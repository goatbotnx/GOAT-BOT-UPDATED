🧩 Command System

GOAT-BOT-UPDATED uses a modular command structure.

Commands can be organized into categories such as:

commands/
├── admin/
├── system/
├── utility/
├── fun/
├── ai/
├── media/
└── owner/

Each command can define its own:

- Name
- Aliases
- Version
- Author
- Permission level
- Cooldown
- Description
- Usage guide
- Event handlers
